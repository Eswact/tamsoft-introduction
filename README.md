# Tamsoft Tanıtım Sitesi

Tamsoft programı için geliştirilmiş kurumsal tanıtım web sitesi.

## Teknolojiler

- **Vue 3** — Composition API
- **Vite** — Geliştirme sunucusu ve build aracı
- **Tailwind CSS** — Stil
- **Vue Router** — Sayfa yönlendirme
- **vue-i18n** — TR / EN dil desteği
- **Swiper** — Slider bileşeni
- **Font Awesome** — İkonlar
